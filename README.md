# 饥荒代码大全

面向《Don't Starve》和《Don't Starve Together》玩家的纯静态物品与控制台指令查询工具。

## 本地预览

无需安装依赖。在仓库目录运行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

然后打开 <http://localhost:4173>。也可以通过静态文件服务器部署到子路径，现有 GitHub Pages 工作流可继续使用。

## 功能

- 生存手册风格的浅色与深色界面，默认跟随系统，支持手动切换并保存偏好。
- 简体中文 / English，首次根据浏览器语言选择，支持跨语言名称、代码、别名、用途和材料搜索。
- 分类筛选、排序、分页、收藏；收藏和界面偏好保存在当前浏览器。
- 物品详情、制作材料、用途关联与 Wiki 链接。
- 选择「背包里 / 地面上」和数量（1–999），一键复制可直接粘贴到游戏的完整指令；顶部「使用指南」提供操作步骤。
- 详情页保留「仅复制物品代码」入口，供需要自行编写指令的玩家使用。
- 数量使用统一的加减控件，支持直接输入和方向键，范围为 1–999。
- 生存笔记每分钟轮换，可手动「换一条」；页面切到后台时暂停计时，切回后重新计时，切换语言保持当前笔记。
- 769 个真实游戏图片随站点发布，不依赖外站图片请求；特殊或旧版本条目无图片时使用分类图标。
- 559 个条目补入联机版基础属性，卡片显示关键数值，详情展示全部已收录数值、版本和来源。食物恢复以新鲜状态为准。
- 保留“饥荒代码大全”标题，补充描述、关键词、分享元信息、正式地址与网站结构化数据。首屏物品直接写入 HTML，`catalog.html` 提供无需 JavaScript 的完整代码表，`sitemap.xml` 列出两个页面。
- 建筑与生物自动使用地面生成；没有独立代码的特殊形态禁用复制。
- `/` 聚焦搜索，`Esc` 清空搜索或关闭弹窗，支持键盘导航与移动端。

点击物品名称查看详情。联机版游戏内执行指令需要管理员权限和远程控制台模式。内容范围及版本差异参见 [SOURCES.md](SOURCES.md)。

## 文件

- `index.html`：页面结构与本地 SVG 插图
- `styles.css`：响应式布局与主题
- `app.js`：双语界面、搜索、详情与复制交互
- `item-details.js`：图片映射与联机版基础属性快照
- `assets/items/`：本地图标及逐文件来源记录
- `scripts/import-item-details.py`：按已记录的数据版本重新导入属性和图片
- `scripts/build-static-catalog.cjs`：更新首屏 HTML、完整代码表与站点地图；修改物品数据或卡片模板后执行 `node scripts/build-static-catalog.cjs`

正式地址沿用原站点 `https://when.run/dont-starve/`；更换域名时需同步修改主页、静态页面生成脚本与站点地图中的地址。中英文界面共用一个 URL，未添加指向同一页面的语言版本链接。`keywords` 用于描述主题，不承诺提高搜索排名。
- `dropdown.js`：统一的语言、主题与排序菜单，支持方向键、回车、Esc 和 Tab
- `data.js`：整理后的物品数据
- `assets/mark.svg`：站点图标

界面不依赖外部字体、CDN 脚本或前端框架。Wiki 链接需要网络访问。
